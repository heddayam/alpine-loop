# IBM Plex

These locally bundled fonts are free under the SIL Open Font License 1.1 in
[OFL.txt](../../../public/fonts/OFL.txt). They come from IBM Plex through Google Fonts and are served
with the app; no font service or network connection is required at runtime.
The license also ships in the built app at `/fonts/OFL.txt`.

IBM Plex Sans uses a variable upright face for weights 400–600. IBM Plex Mono
uses the upright regular face. Both include Latin and Latin Extended subsets.
